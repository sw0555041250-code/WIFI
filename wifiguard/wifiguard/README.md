# חסינת וויפי — פרויקט Android

מחליף את המקרואים "חסימה" ו"נעילה". הקוד ההתחלתי הוא 123456 (כמו במקרו), אפשר לשנות באפליקציה.

## איך בונים APK
**אפשרות א׳ — Android Studio:** פתח את התיקייה, חכה לסנכרון Gradle, ואז Build > Build APK(s).
קובץ התוצאה: `app/build/outputs/apk/debug/app-debug.apk`

**אפשרות ב׳ — בלי מחשבון פיתוח, דרך GitHub:**
1. צור repository חדש והעלה אליו את כל התוכן של התיקייה הזו (כולל `.github`).
2. לשונית Actions > "Build APK" > Run workflow.
3. בסיום, הורד את ה־APK מה־Artifacts.

## הגדרה אחרי ההתקנה
1. התקן את ה־APK ופתח את האפליקציה.
2. לחץ 1 (הרשאת Shizuku) ואשר.
3. לחץ 2 ו־3 ואשר הצגה מעל אפליקציות ופטור מסוללה.
4. כבה את המקרואים "חסימה" ו"נעילה" ב־MacroDroid, כדי שלא יתנגשו.
5. "בדיקת כיבוי עכשיו" מראה ביומן אם `svc wifi disable` באמת עובד.

## דברים שחשוב לדעת
- אחרי אתחול המכשיר צריך להפעיל מחדש את Shizuku (בלי root זה לא קורה לבד), ורק אז החסימה עובדת.
- מי שיכול להסיר את האפליקציה או להשבית את Shizuku יכול לעקוף את החסימה.
